# 💰 Smart Expense Tracker

A responsive web application for managing and tracking daily expenses. Users can add, edit, delete, search, and filter expenses while viewing useful spending statistics.

## 🚀 Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 🔍 Search expenses
- 📂 Filter expenses by category
- 💰 Track total expenses
- 📊 View transaction count and highest expense
- 💾 Store data using browser LocalStorage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
